## Executive ML verdict

The current repository **does not support a claim of fraud/corruption detection,
validated procurement risk, precision/recall, a false-positive rate, causal effect,
or temporal detection generalisation**. It has no independent tender-level outcome
labels. The supervised target is explicitly `(rule_score >= 0.4)`, and the target is
mostly reconstructed from the same or overlapping features. The out-of-time experiment
therefore measures temporal agreement with that internal rule proxy only.

Importantly, the current README, methodology, findings report, dashboard validation
page, model docstrings, and generated validation report now disclose those limits in
direct language. I found no live claim in those surfaces that converts the proxy AUCs
into fraud-detection performance. This is a genuine evidence limitation, not a code bug
that can responsibly be solved by inventing labels.

Engineering/artifact integrity is unusually strong in the committed generation:
all 35 declared configurations are present once and successful; data and protocol
fingerprints recompute; gold/benchmark/ML release manifests validate; and every shipped
detector score, the ensemble, HGB probabilities, agreement flags, contextual score, and
all 75,710 x 20 SHAP values reproduce exactly from the shipped models. Two fail-closed
gaps remain: the protocol fingerprint does not hash implementation source, and the ML
consumer validates the *shape* of `champions.json` but not that its winners and top-K
actually agree with the released leaderboard. Current artifacts pass a manual semantic
cross-check, so these are prospective integrity defects rather than evidence that the
current numerical generation is mixed.

## Claims that are supportable now

1. A static, retrospective feature table and transparent heuristic review queue were
   built for this publication snapshot.
2. Eight unsupervised detector families were benchmarked under the declared internal
   proxy/reproducibility composite; four internally selected families produce a
   snapshot-relative exploratory ranking.
3. The HGB model is a high-fidelity differentiable surrogate for the rule proxy, and
   SHAP attributes that surrogate. It is not independent evidence.
4. The committed benchmark/model/SHAP/scored artifacts are one hash-bound, internally
   consistent generation under the current manifests and manually recomputed semantics.

## Claims that remain unsupported

Fraud/corruption detection; calibrated risk or confidence; causal explanation;
precision, recall, false-positive rate, or detection AUC; superiority to the rule-only
baseline; temporal/general-purpose deployment; score comparability across rebuilt
populations; and external/manual validation. These require evidence not present in the
repository. Current project-facing narrative largely states this correctly.
