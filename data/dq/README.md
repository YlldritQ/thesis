# Data-quality artifacts

Canonical run evidence is generated by `python -m thesis dq run` and uses the
`*.dq.json` / `*.dq.md` naming convention for:

- `silver_tenders`
- `silver_awards`
- `gold_tender_features`
- `gold_tender_summary`

The other CSV files and `summary*.md` in this directory came from deleted
prototype profilers. They are retained only as historical audit traces, are
not consumed by the current pipeline or dashboard, and must not be cited as
current counts or validation evidence. `docs/findings.md` is the canonical
generated numerical report for the submitted snapshot.
